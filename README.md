# BookCrossing

BookCrossing - REST backend для приложения по обмену книгами между пользователями.

## Стек технологий

- **Java 25**
- **Spring Boot 4.0.3** (Web MVC, Security, Validation, Data JPA)
- **PostgreSQL**
- **Liquibase** (миграции БД)
- **Lombok**
- **MapStruct**
- **JJWT** (Access/Refresh токены)
- **YAUAA** (парсинг User-Agent)

## Основные возможности

1. **Регистрация и вход:** создание аккаунта и аутентификация пользователя.
2. **JWT-безопасность:** Access token в ответе API, Refresh token через HttpOnly Cookie.
3. **Ротация refresh token:** обновление сессии с хранением хэша токена в БД.
4. **Контроль сессий:** ограничение количества активных сессий на пользователя.
5. **Локализация (i18n):** сообщения об ошибках и валидации на русском и английском.
6. **Централизованная обработка ошибок:** единый формат API-ошибок.
7. **Профили пользователей:** создание, просмотр и частичное обновление профиля.
8. **Наблюдаемость и логирование:** request tracing через MDC, профилированный Logback и структурные security-логи.

## Архитектура

Проект построен в многослойном стиле с feature-ориентированной организацией:

- `feature/*` - бизнес-функции (auth, user, role, refreshtoken, profile)
- `security/*` - конфигурация безопасности, JWT фильтр и UserDetails
- `config/*` - конфигурация приложения и `@ConfigurationProperties`
- `infrastructure/*` - технические компоненты (локализация, web-error handling)
- `exception/*` - доменные и HTTP-исключения

## Запуск

1. Создайте `.env` на основе [.env.example](.env.example).
2. Поднимите PostgreSQL.
3. Запустите приложение:

```powershell
.\mvnw.cmd spring-boot:run
```

Сервис будет доступен по адресу: `http://localhost:8080`
